# ScriptDesk SVG illustration pack

Original, conceptual category illustrations for camera-equipment UI. All assets are local SVG files; no external image URLs are needed.

Use in HTML/React:
`<img src="/illustrations/gimbal.svg" alt="Camera gimbal illustration" />`

Included: gimbal, camera crane, dolly, drone, tripod, vehicle rig, underwater housing, lens set, matte box, monitor/focus and rain cover.

These are conceptual category drawings, not exact branded product representations or engineering drawings. Verify specific equipment before labeling an illustration as an exact model.

Added for ScriptDesk (same style, conceptual): camera_body.svg, light_panel.svg, motion_control.svg. The build script (scripts/build.py) inlines every SVG in this folder into the app, so the app needs no image files and works offline.
